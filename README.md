# Equipment Requests

A small static web app for tracking staff equipment requests (MIS 4173 Codex Practice Series).

- No login and no database: the sample requests are built in, and requests you add are saved in your browser's localStorage.
- Each request has a priority: High, Medium, Low, or blank (shown as "Unspecified").

## Run it

Open `index.html` in a browser. No build step or install is needed.
